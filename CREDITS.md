# Credits and reuse notes

## Original application

- **Project:** ResumeX
- **Original author:** Rafivali Shaik
- **Source:** https://github.com/rafivalih/ResumeX
- The original React components, form model, template previews, and core resume-building workflow provided the foundation for this version.

## Enhancements in this version

- Redesigned landing page, navigation, builder, review page, template gallery, and resume guide.
- Added the transparent nine-check readiness engine in `src/lib/ats.js`.
- Added the ATS readiness panel and fictional sample-data workflow.
- Connected the previously listed Executive template with a new renderer.
- Improved safe loading of saved data, responsive navigation/preview, keyboard focus, and export guidance.
- Reworked documentation to distinguish implemented features, limitations, and future plans.

## Libraries and fonts

- React, Vite, Tailwind CSS, React Router, Lucide React, and `react-to-print` are used through their existing package definitions.
- IBM Plex Sans, IBM Plex Mono, and Lora are loaded through Google Fonts.
